# Política de Segurança — Kaline IA

A segurança e a integridade de dados e modelos preditivos são fundamentais para o projeto **Kaline IA**.

---

## 🔒 Relatando uma Vulnerabilidade de Segurança

Se você descobrir uma vulnerabilidade de segurança neste projeto, solicitamos que não a divulgue publicamente através do rastreador de *Issues* do GitHub.

Em vez disso, por favor:
1. Abra um [GitHub Security Advisory privado](https://github.com/valteroberdan/kaline-ia/security/advisories/new) ou envie um e-mail diretamente para os mantenedores do projeto.
2. Forneça uma descrição detalhada da vulnerabilidade com etapas de reprodução ou prova de conceito.

---

## 🛡️ Dados Médicos e Privacidade (HIPAA / LGPD)

- Este repositório utiliza exclusivamente **dados de teste anonimizados e dados públicos de código aberto** provenientes da plataforma internacional [VitalDB](https://vitaldb.net/).
- **É estritamente proibido** enviar para o repositório arquivos que contenham Informações de Saúde Protegidas (PHI), nomes de pacientes, prontuários ou metadados hospitalares identificáveis.
